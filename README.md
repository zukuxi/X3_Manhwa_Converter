# X3 条漫转换器

用于将条漫 PDF 或图片文件夹转换为 Xteink X3 使用的 XTC / XTCH 文件。PDF 与图片共用 `zukuxi/test` 的 528 × 792 连续拼接、灰度、抖动和编码流程。

## 输入

- 选择单个或多个文件：支持 PDF、JPG、JPEG、PNG、WebP、BMP、GIF、AVIF，可混合选择。
- 选择整个文件夹：递归读取其中的 PDF 和漫画图片。
- 图片按章节文件夹和自然数字顺序排列；支持 `漫画名/第01话/001.jpg`，也支持 `漫画名/第1卷/第01话/001.jpg` 等多层目录。
- 预览区可切换队列首个文件或任意图片章节，分别查看转换后的前 5 页。
- 根目录 `Cover.jpg` 可在“整部合并成一本”模式下作为第一页。

## 生成方式

图片章节提供四种方式：

- 每章单独一本
- 整部合并成一本
- 指定章节范围合并
- 每 N 章合并成一本

图片章节生成方式与 PDF 合并方式分别设置：PDF 可设置每 1 / 2 / 3 / 4 / 5 / 10 / 20 个文件合并一本，也可启用 PDF 章节模式，将标题相同且章节号连续的文件合并。页面只显示当前输入类型适用的选项。

## 转换设置

- 输出格式：4 灰阶 XTCH 或黑白 XTC。
- 抖动算法：Atkinson、Floyd–Steinberg、Stucki、无抖动。
- 对比度、亮度、黑白阈值和抖动强度。
- 蒙版兼容模式：仅对 PDF 生效，使用 PDF.js 打印渲染模式，默认关闭。

## 输出

- 单独下载每一本。
- 打包为一个 ZIP。
- 选择目标文件夹自动保存（需要支持 File System Access API 的 Chrome / Edge）。

## 转换核心

PDF 页面以 2 倍渲染；图片逐张读取原始分辨率。两种输入最终都使用相同的 528 × 792 连续拼接器，按宽度等比例缩放，0% 重叠，每满 792 像素输出一页，最后一页底部补白。图片逐张处理，不创建整章超长画布。文件均在本机浏览器处理，不会上传到服务器。

## 部署

将 `index.html`、`app.js`、`README.md` 和 `LICENSE` 上传到 GitHub 仓库，并通过 GitHub Pages 部署。
